  <description>Changing an ideoligion's memes no longer rerolls everything.

Kept when you change memes:
- Roles
- Rituals
- Buildings (altars, ideograms...)
- Relics
- Preferred / despised weapons
- Venerated animals
- Preferred xenotypes
- Required apparel
- Appearance (hair, beard and tattoo frequencies)
- Style categories (optional, off by default)

Precepts required by a meme you just added are still added, and kept precepts that need a meme you removed are dropped, so the ideoligion stays valid.

Hold SHIFT while accepting the meme dialog to get the normal vanilla reroll.

Every category can be toggled in Mod Settings. No save data: safe to add or remove mid-save.

Requires Harmony and the Ideology DLC.</description>
